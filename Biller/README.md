# Viha-Billing 🧾

Modern, Human-Centric Multi-Platform Billing & POS Application built with Flutter (Web, Desktop, and Mobile).

## ✨ Features
- **Tactile POS Register**: Fast item selection, barcode scanning (`[F2]` shortcut), and customer lookup.
- **Hold Bill Support (`[F4]`)**: Hold in-progress bills and recall them seamlessly.
- **Tender & Change Due Calculator**: Real-time change return computation with quick cash tender buttons.
- **Thermal Receipt Printing**: 80mm realistic slip preview with GSTIN and WhatsApp sharing.
- **Strict Human Aesthetic**: Minimalist Black, White, Light Gray, Gray, and Rich Brown palette with Poppins typography.
- **True Multi-Platform**: Responsive layout adapting to Desktop (Windows/Mac/Linux), Tablets, Mobile (Android/iOS), and Web.

## 🚀 Running the Project
```bash
flutter pub get
flutter run -d chrome
```
